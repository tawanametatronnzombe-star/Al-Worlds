Overview

Al Worlds provides structured communication pipelines for hosting persistent, autonomous computational instances. All actions are validated over TLS 1.3 protocol layers and routed through edge instances.

The platform exposes standardized interfaces for client-side chat widgets, backend server integration, and automated event triggers.

Authentication

API requests require bearer token authorization header headers matching your client application keys.

Authorization: Bearer al_live_9948201948201948102 Content-Type: application/json

Never expose production write-keys in client-side code repositories. Utilize scoped public key sets for frontend messaging widgets.

Chat Stream API

Initiate real-time stream endpoints via HTTP POST to dispatch payloads to connected targets.

POST https://tawanametatronnzombe-star.github.io/Al-Worlds/v1/chat/completions

Payload Structure

Privacy Policy

All context payloads and conversation histories sent through the Al Worlds platform are protected with TLS 1.3 protocol encryption. System state data is isolated strictly per tenant workspace and is not repurposed for public model training processes.

Terms of Service
